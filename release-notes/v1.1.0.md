# DeviceLib v1.1.0 - Feature Expansion & Enhanced Compatibility

**Release Date:** June 15, 2025  
**Release Type:** 🚀 Feature Release  
**Compatibility:** ✅ Fully backward compatible  

## 🚀 What's New

### 🔌 Enhanced PCF8574/8575 Support
Expanded I2C GPIO expander capabilities for larger projects.

- **Improved Interrupt Handling** - Better responsiveness with PCF interrupt pins
- **Multi-PCF Support** - Connect multiple expanders on the same I2C bus
- **Address Conflict Resolution** - Automatic handling of address overlaps

```cpp
// Multiple PCF expanders
PCF8574 pcf1(0x20);
PCF8574 pcf2(0x21);

GenericButton btn1(pcf1, 0, INPUT, LOW);
GenericButton btn2(pcf2, 0, INPUT, LOW);

// Enhanced interrupt support
GenericInput::attachInterrupt(&pcf1, 2); // INT1 to GPIO 2
GenericInput::attachInterrupt(&pcf2, 4); // INT2 to GPIO 4
```

### ⏱️ Advanced Timing Features
More precise control over button timing and detection.

- **Custom Click Count Detection** - Detect 3, 4, 5+ rapid clicks
- **Variable Hold Times** - Multiple hold time callbacks per button
- **Timing Optimization** - Better performance with GCD-based tick calculation

```cpp
GenericButton btn(10);

// Multi-click detection
btn.onClickCount(3, []() { Serial.println("Triple click!"); });
btn.onClickCount(5, []() { Serial.println("Penta click!"); });

// Multiple hold times
btn.onPressHold(2000, []() { Serial.println("2 second hold"); });
btn.onPressHold(5000, []() { Serial.println("5 second hold"); });
btn.onPressHold(10000, []() { Serial.println("10 second hold"); });
```

### 🎯 Improved State Management
Better tracking and reporting of component states.

- **Enhanced State Reporting** - More detailed state information
- **State Persistence** - Better startup state handling
- **State Callbacks** - New onChange events for state monitoring

## 🛡️ Stability Improvements

### Cross-Platform Compatibility
- **ESP32 Timer Improvements** - Better `esp_timer` handling and error recovery
- **ESP8266 Ticker Enhancement** - More reliable `Ticker` operations
- **Arduino Core Compatibility** - Support for latest Arduino framework versions

### Performance Optimizations
- **Reduced Memory Footprint** - Optimized data structures
- **Faster Response Times** - Improved interrupt handling
- **Better Resource Management** - More efficient timer usage

### Breaking Changes
**None** - All existing v1.0.x code continues to work without modification.

### Deprecation Notices
Some methods are now deprecated but still functional:

```cpp

```

```ini

    nht173/DeviceLib@^1.1.0
```

**Step 2:** Optional - Use new features
```cpp
// Take advantage of new timing features
btn.onClickCount(3, tripleClickHandler);
```

## 🧪 Example Projects

### Advanced Button Interface
```cpp
GenericButton menuBtn(10);

void setupAdvancedInterface() {
    // Single click: Next item
    menuBtn.onClick([]() { nextMenuItem(); });
    
    // Double click: Select item  
    menuBtn.onDoubleClick([]() { selectMenuItem(); });
    
    // Triple click: Quick access
    menuBtn.onClickCount(3, []() { quickAccess(); });
    
    // Short hold: Enter menu
    menuBtn.onPressHold(1000, []() { enterMenu(); });
    
    // Long hold: Admin mode
    menuBtn.onPressHold(5000, []() { enterAdminMode(); });
}
```

### PCF Expansion Example
```cpp
PCF8574 expander(0x20);
GenericButton buttons[8];
GenericOutput leds[8];

void setupExpandedIO() {
    expander.begin();
    GenericInput::attachInterrupt(&expander, 2);
    
    for (int i = 0; i < 8; i++) {
        buttons[i] = GenericButton(expander, i, INPUT, LOW);
        leds[i] = GenericOutput(expander, i, LOW);
        
        buttons[i].onClick([i]() { 
            leds[i].toggle();
            Serial.printf("Button %d pressed\n", i);
        });
    }
}
```
