# DeviceLib v1.0.0 - Initial Release

**Release Date:** May 1, 2025  
**Release Type:** 🎉 Initial Release  
**Compatibility:** ✅ ESP32 & ESP8266  

## 🎉 Welcome to DeviceLib!

The first stable release of DeviceLib brings event-driven programming to Arduino ESP32/ESP8266 projects with a simple, intuitive API designed for IoT applications.

## 🚀 Core Features

### 🎯 Event-Driven Button Handling
Revolutionary approach to button management with callback-based events.

```cpp
GenericButton button(10, INPUT_PULLUP, LOW);

// Simple event handling
button.onClick([]() {
    Serial.println("Button clicked!");
});

button.onDoubleClick([]() {
    Serial.println("Double click detected!");
});

button.onLongClick([]() {
    Serial.println("Long press detected!");
});
```

### 🔧 Smart Output Management
Intelligent output control with timing and state management.

```cpp
GenericOutput led(LED_BUILTIN, LOW, START_UP_LAST_STATE);

// Basic control
led.on();
led.off();
led.toggle();

// Advanced features
led.setAutoOff(true, 5000);  // Auto-off after 5 seconds
led.setPowerOnDelay(1000);   // Delay before turning on

// Event callbacks
led.onPowerOn([]() { Serial.println("LED turned on"); });
led.onPowerOff([]() { Serial.println("LED turned off"); });
```

### ⚡ Built-in Debouncing
Hardware debouncing eliminates false triggers and noise.

- **Configurable timing** - Adjust debounce time per input
- **Interrupt-driven** - Efficient, non-blocking operation
- **Cross-platform** - Works on both ESP32 and ESP8266

### 🔌 PCF8574/8575 Support
Expand your I/O capabilities with I2C GPIO expanders.

```cpp
#include <PCF8574_library.h>
PCF8574 pcf(0x20);

GenericButton btn(pcf, 0, INPUT, LOW);    // PCF pin 0
GenericOutput led(pcf, 1, LOW);           // PCF pin 1

btn.onClick([]() {
    led.toggle();
});
```

## 🛠️ Technical Foundation

### Cross-Platform Timer Support
- **ESP32**: Native `esp_timer` integration for microsecond precision
- **ESP8266**: `Ticker` library integration for reliable timing
- **Automatic selection** - No platform-specific code required

### Memory Efficient Design
- **Minimal footprint** - ~180 bytes per object
- **Event-driven** - No polling loops
- **Optimized callbacks** - Efficient function pointer management

### Flexible Configuration
```cpp
// Customizable button behavior
button.setClickWaitTime(300);    // Multi-click detection window
button.setHoldTime(3000);        // Long press threshold  
button.setIdleTime(500);         // Return to idle timing

// Configurable output behavior
output.setAutoOff(true, 10000);  // Auto-off timing
output.setPowerOnDelay(2000);    // Startup delay
```

## 🎯 Design Philosophy

### Simple but Powerful
DeviceLib follows Arduino's philosophy of making complex things simple while maintaining full flexibility for advanced users.

**Simple:**
```cpp
GenericButton btn(10);
btn.onClick([]() { Serial.println("Clicked!"); });
```

**Powerful:**
```cpp
btn.onClickCount(3, []() { Serial.println("Triple click!"); });
btn.onPressHold(2000, []() { Serial.println("2-second hold"); });
btn.onChange([]() { Serial.println("State changed"); });
```

### Event-Driven Programming
Move from polling-based to event-driven programming for more responsive and efficient code.

**Old Way (Polling):**
```cpp
void loop() {
    if (digitalRead(BUTTON_PIN) == LOW) {
        // Handle button press
        delay(50); // Debounce
        while (digitalRead(BUTTON_PIN) == LOW); // Wait for release
        delay(50); // Debounce
    }
}
```

**DeviceLib Way (Event-Driven):**
```cpp
void setup() {
    button.onClick(handleButtonPress);
}

void loop() {
    // Your main application logic
    // Button handling happens automatically in background
}
```

## 📦 Getting Started

### Installation

**PlatformIO:**
```ini
[env:your_board]
platform = espressif32  ; or espressif8266
board = your_board
framework = arduino
lib_deps = 
    nht173/DeviceLib@^1.0.0
```

**Arduino IDE:**
1. Download DeviceLib from GitHub releases
2. Install via Sketch → Include Library → Add .ZIP Library

### Basic Example
```cpp
#include "GenericButton.h"
#include "GenericOutput.h"

GenericButton button(10, INPUT_PULLUP, LOW);
GenericOutput led(LED_BUILTIN, LOW);

void setup() {
    Serial.begin(115200);
    led.begin();
    
    button.onClick([]() {
        led.toggle();
        Serial.println("LED toggled!");
    });
    
    button.onLongClick([]() {
        Serial.println("Long press - entering setup mode");
    });
}

void loop() {
#ifdef ESP32
    GPIO_Scheduler.run();
#endif
}
```

## 🧪 Example Projects

### Smart Light Switch
```cpp
GenericButton wallSwitch(10);
GenericOutput roomLight(20, LOW, START_UP_LAST_STATE);

void setup() {
    roomLight.begin();
    
    // Single click: Toggle light
    wallSwitch.onClick([]() {
        roomLight.toggle();
    });
    
    // Double click: Full brightness
    wallSwitch.onDoubleClick([]() {
        roomLight.on();
    });
    
    // Long press: Turn off
    wallSwitch.onLongClick([]() {
        roomLight.off();
    });
}
```

### IoT Door Bell
