## 🚀 What's New

### Added

- **Virtual destructors** for `GenericInput`, `GenericButton`, and `GenericOutput` classes
- **Timer cleanup on object destruction** to prevent memory leaks
- **Null pointer validation** in timer callbacks
- **Timer null checks** before operations
- **`clearCallbacks()` method** for `GenericButton` to remove all callbacks
- **`removeCallbacks(event_type)` method** for selective callback removal
- **Cross-platform destructor support** (ESP32 and ESP8266)

### Changed

- **Improved documentation comments** for deprecated methods
- **Enhanced parameter validation** in constructors
- **Better initialization error handling**

### Fixed

- **Memory leaks** from ESP32 `esp_timer` not being properly deleted
- **Memory leaks** from ESP8266 `Ticker` not being detached
- **Race conditions** during object destruction
- **Timer callback execution safety**
- **Potential crashes** when timer callbacks execute during object destruction

## 🛡️ Stability Improvements

### Memory Leak Prevention

```cpp
// Before v1.2.0: Potential memory leaks
{
    GenericButton btn(10);
    btn.onClick([]() { /* callback */ });
    // Timer resources might not be cleaned up properly
}

// After v1.2.0: Guaranteed cleanup
{
    GenericButton btn(10);
    btn.onClick([]() { /* callback */ });
    // Virtual destructor automatically cleans up all timers
} // ✅ No memory leaks
```

### Cross-Platform Timer Management

```cpp
// ESP32: esp_timer cleanup
GenericButton::~GenericButton() {
    if (timer_handle) {
        esp_timer_stop(timer_handle);
        esp_timer_delete(timer_handle);
        timer_handle = nullptr;
    }
}

// ESP8266: Ticker cleanup
GenericButton::~GenericButton() {
    if (ticker_active) {
        ticker.detach();
        ticker_active = false;
    }
}
```

### Enhanced Callback Management

```cpp
GenericButton btn(10);

// Add multiple callbacks
btn.onClick(callback1);
btn.onClick(callback2);
btn.onDoubleClick(callback3);

// New in v1.2.0: Selective cleanup
btn.removeCallbacks(BUTTON_EVENT_CLICK);     // Remove only click callbacks
btn.clearCallbacks();                        // Remove all callbacks
```

## 🔬 Technical Details

### Memory Management Architecture

```cpp
class GenericInput {
    virtual ~GenericInput();  // Virtual destructor for proper cleanup
protected:
    void cleanup_timers();    // Platform-specific timer cleanup
};

class GenericButton : public GenericInput {
    virtual ~GenericButton(); // Calls parent destructor + clears callbacks
private:
    std::vector<ButtonCallback> callbacks;  // Automatically cleaned up
};
```

### Platform-Specific Implementations

**ESP32:**

- Uses `esp_timer_create()` / `esp_timer_delete()` for precise timing
- Automatic timer handle cleanup in destructor
- Thread-safe timer operations

**ESP8266:**

- Uses `Ticker` class for timer operations
- Automatic `detach()` on destruction
- Compatible with interrupt context
